GWO 内容编辑器用于在 Windows 上编辑本地内容包，预览模型、默认配件、手臂和动画，并校验、导出内容包。

## 下载与更新

从 [官方编辑器下载仓库](https://github.com/Sgr792/gwo-editor-releases/releases/latest) 获取安装版或免安装 ZIP。免安装版解压后运行“GWO 内容编辑器.exe”，支持检查更新、校验签名及更新失败回退。升级前保存正在编辑的内容。

当前公开下载版本为 0.4.0；以下也记录已完成的 0.4.1–0.4.3 源码更新，下载时以 Release 中的版本为准。

## 使用流程

1. 打开内容包目录，在左侧选择枪械、配件或弹药配置。
2. 在中央检查枪械及默认配件；切换第一人称，可选择 Steve 或 Alex 手臂。
3. 使用右侧工具编辑配置、配件选择、材质、状态机、动画通道、姿态图和事件。两侧面板可收起或拖动宽度。
4. 调整弹量、瞄准等预览条件，播放动作并检查换弹部件、弹匣和膛内子弹。
5. 保存配置，运行校验，再到游戏中确认实际效果。受保护发布需要有效的发布者令牌，编辑器不会将令牌保存在内容包配置中。

## 安装点

配件安装位置由 Blender 中的骨骼或 Empty 定义。编辑器只读展示挂点，不提供拖动或数值调位。高级区可将当前枪械已有的配件配置偏移归零；要更改模型挂点，应回 Blender 修改并重新导出。

## 透明材质（0.4.3）

在材质工具中选择机匣或已安装配件，再选择模型网格。调整透明度、双面、深度写入和深度测试可以实时预览；点击“保存此网格透明设置”才会写回配置。切换工具或还原未保存预览会丢弃未保存的透明调整。

设置按 GLB 原始节点名称写入；配件设置可以保存为当前枪械的配件覆盖。预览保留 GWO 材质着色逻辑。

## 预览范围

编辑器没有嵌入 Minecraft。光影包、碰撞、服务器逻辑、镜内渲染和完整程序化相机行为仍需进游戏测试；抛壳使用预览代理，自定义扩展命令可能只保留数据而不执行。
