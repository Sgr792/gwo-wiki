# 从 Blockbench 制作源接入 GLB

GWO 枪械内容包使用 GLB/glTF 模型和 GLB 动画库。Blockbench 的 `.bbmodel` 是制作源文件，需要导出或转换为 GLB 后再接入；改文件扩展名不能完成格式转换。

转换后核对节点名称、层级、UV、枢轴和动画剪辑，并按 GWO 的骨架与挂点规则整理模型。

继续查看 [Blender 骨骼蒙皮](./blender-skinning.md)、[Blender Empty](./blender-empty.md)与[格式配置](./bedrock-empty.md)。
