# 内容包制作教程

请从左侧目录选择章节。第一次制作时，建议按照目录顺序阅读。

1. [快速开始](getting-started.md)：环境、目录结构、资源 ID 和推荐制作顺序。
2. [模型制作规范](models.md)：Blender 3.3、坐标、骨架、Empty/刚性节点、挂点和 GLB 导出。
3. [动画制作与导出规范](animation.md)：全部动画用途、状态区别、通道所有权、交接和动画机配置。
4. [枪械、弹药与材质](firearms.md)：枪械逻辑、弹道、显示变换、后坐力、特效和贴图。
5. [配件、瞄具与挂饰](attachments-optics.md)：配件挂点、替换动画、瞄具、侧瞄和动态挂饰。
6. [独立近战武器](melee.md)：近战动作集合、连段、命中窗口和声音。
7. [声音、图标与界面资源](audio-ui.md)：声音事件、语言文件、物品图标和 HUD。
8. [调试、验收与发布](debugging-release.md)：常见故障、性能检查、完整验收和 ZIP 发布。
9. [参考文件](reference.md)：当前官方内容包中各类完整范例的路径。
