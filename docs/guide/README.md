# 内容包制作教程

第一次制作请先走完“零基础实战”，遇到具体字段时再查后面的技术参考。不要从完整武器 JSON 中盲目复制两千行配置。

## 零基础实战

1. [快速开始](getting-started.md)：安装环境、理解资源格式和制作路线。
2. [下载并使用空内容包模板](empty-template.md)：取得目录正确、没有旧字段的空包。
3. [从零制作第一把枪](first-firearm.md)：从空目录到能显示、射击、换弹，再逐步加入手臂、瞄准、声音与配件。

## 完整章节导航

1. [模型制作规范](models.md)：Blender 3.3、坐标、骨架、Empty/刚性节点、挂点和 GLB 导出。
2. [动画制作与导出规范](animation.md)：全部动画用途、状态区别、通道所有权、交接和动画机配置。
3. [枪械、弹药与材质](firearms.md)：枪械逻辑、弹道、显示变换、后坐力、特效和贴图。
4. [配件、瞄具与挂饰](attachments-optics.md)：配件挂点、替换动画、瞄具、侧瞄和动态挂饰。
5. [独立近战武器](melee.md)：近战动作集合、连段、命中窗口和声音。
6. [声音、图标与界面资源](audio-ui.md)：声音事件、语言文件、物品图标和 HUD。
7. [调试、验收与发布](debugging-release.md)：常见故障、性能检查、完整验收和 ZIP 发布。
8. [参考文件](reference.md)：当前格式的典型文件名称和已废弃字段。
