# 金属倒伏靶

`gwo:training_target` 是本体自带的两格高训练靶，不需要内容包。可在创造栏“其他”取得；生存模式用五个铁锭、一个原版标靶和一个红石粉合成。放在有坚固支撑、前方留有倒下空间的位置，朝向按玩家放置方向确定。

只有子弹击中印有靶环的**正面靶板**才会倒下并向射击者显示命中读数。背面、侧面和底座会挡弹，却不触发倒下。靶板约 0.25 秒倒下，倒地约 1 秒，约 0.45 秒起身；完整周期约 1.7 秒。倒地板面仍能挡住子弹，但不会重复计为有效靶板命中或播放靶子命中音。倒地后右键可提前复位，破坏靶子或其支撑方块可回收物品。

靶子使用本体提供的 Bedrock JSON 模型和动画。制作其他内容包时无需复制其文件；若测试射击逻辑，请分别验证正面、背面、底座和倒地期间的命中。实现细节见[本体训练靶说明](https://github.com/Sgr792/gwo/blob/main/docs/training-target-block.md)。
