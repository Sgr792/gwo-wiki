# Blender：Empty 刚性动画

[返回制作方式选择](./choose-workflow.md)

适用于整体移动、旋转、缩放的部件，不适用于靠权重弯曲的手臂或布料。需要包含本次格式更新的开发版；游戏验收仍待完成。

## 1. 软件与工程

在 Blender 中建立独立工程。先制作机匣与一个可动部件，保存工程，不需要创建 Armature。

## 2. 模型与坐标

制作网格，保持枪口朝 `+X`。在开始动画前统一模型单位和变换。网格原点、Empty 原点与父子关系是不同概念，不要靠反复移动原点修补错误的父级。

**完成标准：**各部件静态装配正确，网格没有蒙皮修改器或误留的骨架依赖。

## 3. Empty 层级与挂点

创建 Empty 作为参考节点，将网格设置为相应 Empty 的子物体。正式第一人称武器沿用以下主链：

```text
root (Empty)
└─ tag_view (Empty)
   ├─ tag_camera (Empty)
   └─ tag_ads (Empty)
      └─ tag_weapon (Empty)
         └─ weapon_body (Empty)
            ├─ receiver (Mesh)
            └─ bolt (Empty)
               └─ bolt_mesh (Mesh)
```

`bolt` 的原点就是枪机运动参考点；移动或旋转它时，`bolt_mesh` 应跟随。其他挂点的职责见[模型规范](./models.md)。

设置父级时检查是否产生额外父级逆变换。不要同时把父物体的运动烘焙到子网格，否则会重复应用。

**完成标准：**手动移动父 Empty，子网格跟随；还原变换后装配位置不变。

## 4. UV 与材质

UV 在 Mesh 上制作，不是在 Empty 上制作。基础色、法线、材质贴图仍按[共用材质规则](./firearms.md)配置。

## 5. 刚性动画

选中要运动的 Empty，在需要的帧设置位置、旋转或缩放关键帧。网格本身也可以有对象动画，但通常把机构运动集中在 Empty 上更易管理。

- 使用唯一节点名。
- 先做一个简单移动动作，再扩展到掏枪、开火与换弹。
- 每个动作只包含需要的轨道；参考[动画规范](./animation.md)中的状态与轨道职责。
- 约束和驱动器必须烘焙成普通变换关键帧。

**完成标准：**运动部件不变形，动作起止位置一致，没有父子双重运动。

## 6. 导出与检查

导出 GLB 时包含完整 Empty 层级及子网格，并启用动画导出。仅选择网格会丢失驱动节点。

可将模型和动作放在同一个 GLB，也可分为模型与动画库。分开时，两份文件必须具有一致的节点名、父子级与初始变换。

新建空工程重新导入，检查 Empty 是否保留、动作是否存在，以及子网格是否跟随。当前新增支持是纯刚性无 Skin 路线，不承诺复杂混合骨架导出。

**完成标准：**重新导入后动作正确。按[格式配置示例](./bedrock-empty.md)接入，再进入[快速开始](./getting-started.md)和[共用配置教程](./first-firearm.md)。
