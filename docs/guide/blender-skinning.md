# Blender：骨骼蒙皮

[返回制作方式选择](./choose-workflow.md)

这条路线用于普通精细网格与需要变形的模型。枪身可使用单骨骼全权重；手臂、手指则使用合理的多骨骼权重。

## 1. 软件与工程

- 准备 Blender；本教程的手臂模板使用 Blender 3.3。
- 保存独立工程副本，先做机匣、弹匣和一个运动机构，不急着加入全部配件。
- 需要手臂时，可下载[手臂模板](/downloads/gwo_arms_template_blender33.blend)。文件实际下载入口也见[模型规范](./models.md)。

**完成标准：**工程可以保存、重新打开，模型和骨架来源清楚。

## 2. 模型与坐标

确认枪口朝模型 `+X`。命名机匣、弹匣与可动网格；玻璃和需要独立隐藏的部分使用独立网格。

在建立动画前统一旋转、缩放与参考空间。动画完成后不要单独应用骨架或网格变换，否则会改变绑定关系。

**完成标准：**模型大小、朝向、法线正确，没有重叠的重复部件。

## 3. 骨架、挂点与权重

按[模型规范的主链](./models.md)建立第一人称参考节点。用骨骼驱动需要运动的部分，挂点位于对应运动分支下。

- 刚性枪身部件：对应顶点对所属骨骼赋完整权重。
- 手臂：检查肘部、手腕与手指的变形，不把整只手分配给枪身骨骼。
- 使用姿态模式逐个旋转骨骼，检查是否只影响预期网格。

**完成标准：**移动弹匣骨骼只带动弹匣；手臂可自然弯曲；挂点随所属部分移动。

## 4. UV 与材质

展开 UV 并制作基础色。先确认无光影基础色正常，再准备法线、反射和自发光资源，规则见[枪械与材质](./firearms.md)。

Blender 中看到的材质节点效果不会全部自动转成 GWO 的材质配置。

**完成标准：**纹理在重新导入的模型上没有明显错位。

## 5. 动画制作

先制作 `static_idle`、`draw`、`fire`，需要换弹时再加入 `reload` 与 `reload_empty`。

给骨骼的局部变换设置关键帧，并给每个剪辑明确名字。姿态层、相机轨道、禁止轨道与动作交接必须按[动画规范](./animation.md)检查；不是所有骨骼都应该在所有动作里打关键帧。

**完成标准：**每个动作可以单独播放，起止姿态符合预期，动作名没有重复。

## 6. 导出与检查

推荐分别导出模型 `.glb` 与动画库 `.anim.glb`。包含所需 Armature、网格和蒙皮；动画库与模型的节点名、父子级及绑定姿态一致。

在空工程中重新导入导出的文件，检查动作数量、时长、初末帧、权重与挂点，而不只看导出是否报错。

**完成标准：**重新导入后的模型与动画正确。随后进入[快速开始](./getting-started.md)和[共用配置教程](./first-firearm.md)。

不需要再学习 Empty 或 Blockbench 路线。
