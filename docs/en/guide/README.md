# Content-Pack Authoring Guide

Use the sidebar in order. Existing content should be copied from the closest weapon class and then adjusted, rather than assembled from unrelated examples.

## Complete chapter index

1. [Getting Started](getting-started.md): environment, directory layout, resource IDs, and production order.
2. [Model Rules](models.md): Blender 3.3, coordinates, skeletons, Empty/rigid nodes, anchors, and GLB export.
3. [Animation Rules](animation.md): every animation purpose, state distinction, channel ownership, handoff, and state-machine configuration.
4. [Firearms and Ammunition](firearms.md): behavior, ballistics, display transforms, recoil, effects, and materials.
5. [Attachments and Optics](attachments-optics.md): anchors, replacement animation, optics, tactical stance, and dynamic charms.
6. [Melee Weapons](melee.md): attack sets, combos, hit windows, and sound.
7. [Audio and UI](audio-ui.md): sound events, language files, item icons, and HUD resources.
8. [Debugging and Release](debugging-release.md): common failures, performance checks, acceptance, and ZIP release.
9. [Reference](reference.md): paths to complete examples in the current official content pack.
